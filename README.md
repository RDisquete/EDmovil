# 📱 ED Móvil — Fibra, Móvil y TV  
### Plataforma de comparación y contratación de servicios de telecomunicaciones

Plataforma web desarrollada para facilitar la comparación de tarifas de fibra, móvil y televisión, priorizando claridad, velocidad de decisión y experiencia de usuario.

---

## 🎯 Contexto

Proyecto orientado a simplificar la contratación de servicios de telecomunicaciones, donde el usuario normalmente se enfrenta a demasiadas opciones y poca claridad en la comparación de precios.

El objetivo fue reducir fricción en la toma de decisiones.

---

## ⚠️ Problema

- Comparación de tarifas poco clara para el usuario final  
- Exceso de información sin jerarquía visual  
- Procesos de contacto poco directos  
- Baja conversión en entornos de navegación móvil  

---

## 🧠 Solución

- Estructura visual centrada en comparación directa de planes  
- Diseño mobile-first para decisiones rápidas  
- CTAs estratégicos para guiar la conversión  
- Simplificación del flujo de navegación (menos pasos, menos fricción)  
- Validación de formularios de contacto para evitar errores de entrada  

---

## ⚙️ Stack

HTML5 · CSS3 · JavaScript · Netlify (CI/CD)

---

## 🚀 Resultado

Plataforma clara y directa que permite al usuario comparar tarifas y contactar de forma rápida sin distracciones ni procesos innecesarios.

---

## 📊 Impacto

- Reducción de fricción en el proceso de comparación  
- Mejora en la navegación desde dispositivos móviles  
- Flujo de contacto más directo y accesible  
- Base lista para escalar con nuevas tarifas o servicios  

---

## 🧪 Calidad técnica

Se implementaron pruebas básicas sobre lógica de interacción y formularios para asegurar estabilidad en producción.

- Validación de formularios de contacto  
- Comprobación de renderizado de ofertas  
- Verificación de comportamiento en navegación responsive  

Integrado en flujo de despliegue para evitar regresiones.
