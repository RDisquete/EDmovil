# 📱 ED Movil | Fibra, Móvil y TV
### "Conectividad de alta velocidad al mejor precio."

Este repositorio contiene el desarrollo de la plataforma web para **ED Movil**, una interfaz moderna y optimizada diseñada para facilitar la contratación de servicios de telecomunicaciones (Fibra Óptica, Telefonía Móvil y Televisión).

---

## 🚀 El Proyecto

La web de ED Movil ha sido construida enfocándose en la **experiencia de usuario (UX)** y la **claridad visual**. El objetivo principal es que el cliente pueda comparar tarifas y encontrar la mejor opción de conectividad de forma rápida y sencilla.

### 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3 y JavaScript.
* **Despliegue:** [Netlify](https://edmovil.netlify.app/) (Integración continua).
* **Diseño:** Responsive Design (Optimizado para móviles, tablets y escritorio).
* **Iconografía:** Librerías de iconos modernos para una navegación intuitiva.

---

## 🎨 Características Principales

1. **Catálogo de Tarifas Interactivo:** Presentación clara de planes de fibra y móvil con énfasis en el ahorro.
2. **Navegación Fluida:** Estructura de "One Page" o multipágina optimizada para reducir la tasa de rebote.
3. **Llamadas a la Acción (CTA):** Botones estratégicos para convertir visitantes en clientes potenciales.
4. **Optimización SEO:** Estructura de etiquetas preparada para posicionamiento en buscadores locales.
